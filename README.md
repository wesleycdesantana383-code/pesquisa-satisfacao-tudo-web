# 📊 Sistema de Pesquisa de Satisfação - TudoWeb

Projeto desenvolvido em **Python** para coletar, processar e exibir estatísticas de uma pesquisa de satisfação de atendimento ao cliente da empresa **TudoWeb**.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3
* **Conceitos aplicados:** 
  * Estruturas de repetição (`for` e `while`)
  * Estruturas de decisão (`if`, `elif`, `else`)
  * Tratamento básico de exceções (`try/except`)

---

## 📋 Requisitos do Sistema
O programa realiza as seguintes etapas:
1. Coleta o nome, idade e a opinião de 50 entrevistados (com opção de teste configurável).
2. Valida as entradas de opinião considerando as alternativas:
   * **[1] EXCELENTE**
   * **[2] BOM**
   * **[3] RUIM**
3. Exibe ao final o somatório total das respostas **EXCELENTE** e **RUIM**.

---
